Publications.

HyperShadow: A Benchmark for Detecting 3D Projections of Higher-Dimensional Spatial Objects

Author: Akshay Sasi

arXiv preprint · cs.LG, cs.CG · July 2026

arXiv Code Dataset Models Article

A 190k-parameter PointNet achieves 96.6% accuracy distinguishing native 3D point clouds from projections of 4D–6D objects. Novel "rigidity witness" statistic reaches AUROC 0.982. Dataset: 10,800 point clouds + 1,800 rotating sequences.

We introduce HyperShadow, a benchmark and lightweight model suite for the task of classifying whether a 3D point cloud is a native 3D object or the orthographic projection ("shadow") of a higher-dimensional spatial object (4D–6D). A 190,000-parameter PointNet baseline achieves 96.6% accuracy on this novel task. We also propose the rigidity witness — a parameter-free geometric statistic that achieves AUROC 0.982, providing an interpretable counterpart to the learned classifier. The dataset contains 10,800 static point clouds and 1,800 rotating projection sequences generated from synthetic 4D–6D convex polytopes, released under CC BY 4.0. Code, model weights, and the full dataset are open-sourced.

Unveiling the Heart-Brain Connection: An Analysis of ECG in Cognitive Performance

Authors: Akshay Sasi, Malavika Pradeep, Nusaibah Farrukh, Rahul Venugopal, Elizabeth Sherly

arXiv preprint · 2026

arXiv Code

Presented at the International Conference on Artificial Intelligence for Healthcare (AIHC 2025), National Institute of Technology Calicut, December 2025.

This study investigates electrocardiogram (ECG) signals as non-invasive indicators of cognitive load. Heart rate variability (HRV) features — time-domain, frequency-domain, and nonlinear measures (Catch22 feature set) — are extracted via Neurokit2 and combined with EEG features processed with MNE. A multimodal classifier trained on these features achieves 92% accuracy in predicting cognitive load levels across subjects. Key predictors include SDNN, RMSSD, and the LF/HF ratio. Our findings establish a reliable, non-invasive pathway toward cognitive state monitoring, with applications in adaptive learning systems and human–computer interaction.
